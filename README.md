# Task-04: Social Media Sentiment Analysis

## Overview

This project analyzes social media data to understand **public opinion and sentiment toward different topics and brands**. The posts are categorized as **Positive, Negative, Neutral, or Irrelevant**.

## Analysis

- Cleaned and prepared the dataset
- Analyzed overall sentiment distribution
- Compared sentiment across different topics
- Identified topics with the highest positive and negative sentiment
- Created visualizations to understand sentiment patterns

## Key Findings

- **Negative sentiment** is the most common overall.
- **MaddenNFL** has the highest negative sentiment at approximately **72%**.
- **NBA2K** has the second-highest negative sentiment at approximately **63%**.
- **AssassinsCreed** has the highest positive sentiment at approximately **64%**.
- Sentiment varies considerably across different topics.

## Conclusion

The analysis shows that social media sentiment differs significantly across topics. These patterns can help understand **public perception and attitudes toward different brands, games, and subjects**.
